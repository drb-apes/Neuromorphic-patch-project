# Neuromorphic-patch-project
Reactive Mind FaA 1.5 cm neuromorphic skin patch that detects biochemical stress and EEG fatigue using microfluidics, FSCV sensors, and a Quad‑SPI ASIC. The hardware upgrade adds 4× bandwidth, improved potentiostat stability, multiplexed interrupts, enhanced cortisol sensing, and integrated zero‑knowledge neuroprivacy.
